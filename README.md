# HAKIM EDU Ω — المنظومة التعليمية الوكيلة

منظومة ذكاء تعليمي متمحورة حول المعلم الفلسطيني: تفهم الغاية، تخطط، تنفذ الأعمال المسموح بها، تتحقق من المخرجات، وتسترد المسار عند فشل الأدوات أو المزودات. الهدف هو إعادة أكبر قدر ممكن من الوقت والجهد إلى المعلم، مع خدمة الطالب والأسرة والمدرسة والجهات التعليمية ضمن الصلاحيات والسياسات.

## المبدأ التشغيلي

`النية → السياق → التخطيط → التنفيذ → التحقق → النقد → الإصلاح → Regression → الموافقة → التسليم → التعلم`

المستخدم النهائي لا يحتاج إلى معرفة الذكاء الاصطناعي أو كتابة Prompts تقنية. يعبّر عن حاجته بلغته الطبيعية، ويحوّلها النظام إلى مهمة قابلة للإدارة. لا تتوقف المهمة بسبب فشل مسار واحد إذا كان هناك بديل آمن؛ ينتقل النظام إلى إعادة المحاولة أو تغيير الطريقة أو مزود بديل أو محرك محلي/حتمي أو تقسيم المهمة.

## هوية مؤسسية

المسار المستهدف هو Microsoft Entra ID للحسابات المؤسسية، مع تكامل Microsoft Graph وTeams وSharePoint/OneDrive وCalendar وEducation APIs وفق الصلاحيات والموافقات المؤسسية. القدرة التقنية لا تعني السلطة: كل إجراء خارجي يخضع للصلاحية والنطاق ومستوى المخاطر والموافقة المطلوبة والتدقيق.

## الذكاء متعدد الطبقات

يمكن توجيه المهام إلى Gemini أو مزودات أخرى وفق نوع المهمة، مع الحفاظ على fallback محلي/حتمي للوظائف المدعومة. مفاتيح المؤسسة تبقى خادمية ولا تُوضع في المستودع؛ BYOK خيار منفصل يملكه المستخدم صراحة.

## التعليم والجودة

المخرجات ليست نصوصًا مولدة فقط. تمر عبر مواصفات منظمة وتحقق بيداغوجي ولغوي ومصدري ورياضي وبصري قبل اعتبارها جاهزة. المحتوى الشرعي يخضع لحارس مصادر وأدلة، ولا تُنسب آية أو حديث بلا تحقق. الترتيب الرياضي والعدّ البصري صريحان ولا يعتمدان على BiDi أو RTL لإنتاج المعنى.

## الاستمرارية

حالة كل مهمة قابلة للاستئناف، وتشمل الهوية والسياق والخطة والحالة والخطوات المنجزة والمعلقات والعوائق والأدلة والمخرجات والموافقات ومحاولات الاسترداد والإجراء التالي. انقطاع الجلسة أو فشل مزود لا يفترض إعادة العمل من الصفر.

## المنتج المستهدف

- Teacher Agent لتخفيف الأعمال اليومية والتنفيذ نيابة عن المعلم ضمن الصلاحيات.
- Student Learning Agent للدعم والتكيف والتغذية الراجعة ضمن سياسات حماية الأطفال.
- School/Ministry intelligence للعمليات والمؤشرات المصرح بها دون كشف غير لازم للبيانات الفردية.
- Knowledge Fabric للمناهج والمصادر والسياسات.
- Assessment, Quality, Evidence, Security, Automation وLearning agents.
- Teams teaching workflows، بما فيها مسارات مساعد المعلم والتدريس المصرح به نيابة عنه؛ أي استخدام صوت/صورة اصطناعية يجب أن يكون معلنًا وواضحًا وليس انتحالًا للمعلم.
