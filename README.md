# مساعدي الذكي Ω

واجهة عربية مستقلة للمحادثة مع Google Gemini بشكل اختياري، مع رفع الملفات وحفظ المفتاح محليًا في المتصفح.

## الاستخدام

افتح الموقع، اذهب إلى الإعدادات، أضف مفتاح Gemini اختياريًا، ثم تحدث وارفع الملفات.

> لا تضع أي API key داخل GitHub. المفتاح يُحفظ في localStorage على جهاز المستخدم فقط.

## النشر

المشروع مصمم للنشر عبر GitHub Pages باستخدام GitHub Actions.
